Colores Multunavegador

Hay más de 160 colores, que son compatibles con todos los navegadores modernos. Estos nombres se pueden usar directamente em el archivo de estilos, para
por ejemplo:

  1. Negro
  2. Blanco
  3. Salmon
  4. Azul
  5. Verde

Colores de un borde

Para queun elemento HTML podamos asignarle un color a su borede son necesarias dos propiedades: <border-style> y <boreder-color>, adicionalmente se puede modificar su tamaño utilizando <border-width>.

Degradado de colores

En CSS podemos aplicar dos tipos de degradado de colores:

Degradado Lineal

El degradado lineal es una trancicion de un color a otro de forma lieneal.

Degradado radial

El degradado radial es una trancicion de un color a otro de forma radial.

Conceptos principales de HTML

HTML

Lenguaje de marcado d eHipertexto que se utiliza para la estrcuturacion de paginas web

Elemento HTML

Es la unidad basica de estructura y contenido de una pagina web, etsa compuesta de

  1. Etiquete de apertura
  2. Pares atruibuto/valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

Contiene la información técnica y los metadatos del documento. Esta sección no es visible directamente para el usuario en la pantalla, pero incluye configuraciones vitales para el navegador, como el título de la página, la codificación de caracteres y los enlaces a las hojas de estilo (CSS).

Etiqueta <body>

Representa el cuerpo del documento y engloba todo el contenido visible de la página web. En esta sección se colocan y estructuran todos los elementos con los que el usuario interactúa, tales como textos, imágenes, enlaces, botones, formularios y contenedores.

Contenedores Semanticos

Conceptos y Definiciones
<header> Representa el contenido introductorio de una pagina (a menudo contiene un logotipo, menu de navegacion u otra informcion de identificacion del sitio de )
<nav> representa una seccion de una pagina que contiene elaces a otras paginas o secciones del sitio. Se usa para enlaces de navegacion que ayudan a los usuarios a navegar por nuestro sitio web
<main> Representa el contenido principal de una pagina (no debe incluir ningun contenido que se repita en varias paginas como menus de navegacion, pies de paginas o barras laterales)
<section>/th> Representa una seccion de una pagina que agrupa conteido relaconado dentro del sitio web (se puede utilizar para dividir una pagina en varias secciones o agrupar contenido dentro de una seccion mas grandes)
<article> Representa una unidad autonoma de contenido o historia que puede distribuirse o reutilizarse de forma independiente, por ejemplo, publicaciones de blogs, articulos de noticias o reseñas de productos
<footer> rpresenta el contenido de cierre de una pagina o seccion / la parte inferior de una pagina o seccion (a menudo contiene informcion de derecchos de author, detalles de contacto, ubicacion u otra informacion complementaria)

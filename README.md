## 📖 Cómo navegar por este repositorio

1. **Comenzar con tareas básicas**: Inicia con la Tarea 01 para entender los fundamentos de HTML
2. **Progresión gradual**: Avanza secuencialmente para construir conocimiento
3. **Tareas con CSS**: A partir de la Tarea 07, encontrarás carpetas `css/` con hojas de estilos
4. **Recursos multimedia**: Las tareas 04, 06, 09, 11, 13, 14 y 15 incluyen carpetas `img/` para imágenes
5. **Tecnologías avanzadas**: Explora las secciones DTD, EjeciciosXML y PruebaXSL para aprender XML y XSLT

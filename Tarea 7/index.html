FORMAS DE AGREGAR ESTILOS A UNA PAGINA WEB (HTML)

Estilos en linea

estos estilos se agregan directamente en el elemento HTML mediante el atributo style

Este parrafo tiene un fondo agregado con estilos en linea

Estilos Internos

estoas estilos se agregan en el mismo estilo html dentro del elemento <style>, este elemento debe estar dentro de la etiqueta <head>

Estilos Externos

son los recomendados ya que ofrecen modularidad, facil mantenimiento, orden, eficienvcia, entre otras ventajas, para agragar una hoja de estilos externos dentro de la etiqueta <head> se va a utilizar la etiqueta <link>
